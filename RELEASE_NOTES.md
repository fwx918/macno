## macno 1.1.0

- Open local HTML and HTM files in a static preview, switch to source, and save edits as HTML. The preview can load images and styles from the document folder. Page scripts and remote assets are disabled.
- Keep Markdown, TXT, and HTML documents open in separate tabs. Each tab retains its own editing state and unsaved changes.
- Right-click documents in Files, Recent, or the tab bar to create a copy, copy a full or folder-relative path, or select the file in Windows File Explorer.
- Recognize Markdown, TXT, and HTML at a glance with distinct monochrome file icons.
- Open UTF-8 HTML and TXT, including files with a BOM. macno warns before editing files it cannot reliably decode.

Download the Windows x64 installer (`macno-1.1.0-win-x64.exe`) or the portable app (`macno-1.1.0-portable.exe`). Compare the download against `SHA256SUMS.txt` to verify the file.
